# OnlineNavigation

This repository contains the online version of Navigation Task. The built Unity project is within the Navigation folder. The code for the Unity project in the NavigationTask folder. It is deployed using a Psiturk container, and it is hosted using Heroku so it is connected to the web. Data is in the form of a JSON object, and it is sent using POST requests to a PostgreSQL database in Heroku. Webpages are designed used HTML, and webpages are connected using Node.js
