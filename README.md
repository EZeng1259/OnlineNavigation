# OnlineNavigation

This repository contains the online version of Navigation Task. The built Unity project is within the Navigation folder. The code for the Unity project in the NavigationTask folder. It is deployed using a Psiturk container, and links are generated by Heroku to access on web. I use REST APIs transfer Unity experimental data to a PostgreSQL relational database. Webpages containing the consent form, instructions, and survey are designed used HTML/CSS. This front-end application is interfaced with Node.js to Psiturk.
