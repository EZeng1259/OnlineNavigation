# OnlineNavigation

This repository contains the online version of Navigation Task. The Unity project is in the Navigation Task folder, and the built and deployable Unity project is within the Navigation folder. The complete experiment is then deployed with PsiTurk, including the main experiment, a consent form, and a survey. The PsiTurk experiment is hosted on the Heroku PaaS application, where I generated links so participants can access the experiment. I create REST API endpoints in Node.js to transfer Unity experimental data to a PostgreSQL relational database. The webpages (e.g. instructions, consent form) are designed using HTML/CSS. Webpage functionality (e.g. buttons, timeout) are managed with JavaScript.
